# Vault Steward Skill

All behavioral rules are defined in VAULT.md. Read VAULT.md first.

## Capture Workflow

1. New note goes to 00-inbox/ first.
2. Apply template from 90-system/Templates/.
3. Fill required frontmatter.
4. Add tags from taxonomy.
5. Link to at least 2 related notes.
6. Regenerate indexes.

## Review Workflow

1. Check 00-inbox/ for unprocessed notes.
2. Triage each: move to the matching PARA folder.
3. Add links to orphaned notes.
4. Update Home.md MOC if new topics emerged.
5. Log session.
6. Regenerate indexes.
