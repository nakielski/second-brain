**Required (all notes):** uid, title, type, status, created, updated.
**Required (wiki pages only):** additionally summary, tags.
**Optional:** priority, related, sources, description, plus type-specific fields.

**Type values:** note, project, meeting, decision, daily, concept, entity, source, comparison, standard, skill.
(MOC files use type: note + tag moc.)

**Status values:** active, review, promote, legacy, backlog.

**UID:** `type-` prefix + first 8 hex chars of SHA-256(creation date + filename slug). Example: a concept page `atr-trailing-stop.md` created 2026-08-16 gets `concept-` + 8 hex of SHA-256("2026-08-16atr-trailing-stop"). Deterministic — the same inputs yield the same uid, so any agent can verify or regenerate it. Assigned once at creation, never changed, never regenerated by index rebuilds. Placeholder uids (`YYYYMMDD-XXXXXX` patterns) are invalid.
