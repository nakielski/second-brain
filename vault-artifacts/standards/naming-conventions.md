**Default:** kebab-case for all file and folder names.

**Exceptions:**
- Folder names may use numeric prefixes (`00-inbox/`, `90-system/`).
- Root-level files (`VAULT.md`, `AGENTS.md`, `Home.md`) use Title Case.
- MOC files: `_<Area> MOC.md`.
- Comparison files: `x-vs-y.md`.
- Template/Operation/Standard/Skill files use Title Case.
- raw/ files: `YYYY-MM-DD_original-name.ext`.
- Note titles use Title Case; filenames remain kebab-case.
