- Agent rules (SINGLE SOURCE OF TRUTH):
  1. **Search before create.** Always check if a note already exists.
  2. **Never delete.** Move to 06-archive/. When archiving: first list all incoming links to the file, then either update them to the archived path or mark them as archived in the linking pages.
  3. **Never modify raw/.** The raw/ directory is immutable. EXCEPTION: during ingest, the agent MAY move/rename files within raw/ and create `.extract.md` / `.transcript.md` companions. See VAULT.md rule 3 for details.
  4. **Preserve frontmatter.** YAML properties always intact. `uid` and `updated` are mandatory: uid = type prefix + first 8 hex chars of SHA-256(creation date + filename slug) — deterministic, assigned once at creation, never changed, never generated by index-rebuild-procedure.md. Placeholder uids (`YYYYMMDD-XXXXXX` patterns) are invalid.
  5. **Link generously.** Use UID lists for `related` and `sources` in frontmatter; use [[Wikilinks]] in the note body.
  6. **Log everything.** Every ingest/query/lint/review appends to wiki/log/. Every write produces a write-log line per the Write Log Standard — including renames, archives, and index regenerations. A write-hook server (e.g. an MCP server) writes these lines itself; agents append to `.vault-write-log.jsonl` only when writing directly. **Concurrency:** the write log is the coordination surface. If verification reports two actors wrote the same path within a short window, resolve the conflict before further writes to that path. For multi-agent setups: Git is strongly recommended, one branch per agent.
  7. **Update indexes.** Every operation that creates or modifies wiki/ or agent-memory/ files MUST regenerate indexes via index-rebuild-procedure.md — unless a write-hook server maintains that index; then the server does it and agents do not edit the index file.
  8. **Show diffs.** Before multi-file changes. Applies only to modifications of EXISTING files after bootstrap.
  9. **Write summaries.** Every session with changes ends with a Session Log entry.
  10. **Respect status.** Notes with status: legacy not for current work.
  11. **Privacy first.** Read 05-people/, user-context.md, and entity_type: person pages ONLY on explicit user request.
- **These rules are the SINGLE SOURCE OF TRUTH.** Precedence: VAULT.md > AGENTS.md > CLAUDE.md > Skills.
