# Obsidian Base Configuration

This file documents the required Obsidian settings.

## Templates
- Register the templates folder at `90-system/Templates/`
- Set Templater as the default template engine

## Daily Notes
- Set the daily notes folder (per Q4 answer)
- Template: `90-system/Templates/Daily Note Template.md`

## Link Updates
- Enable "Automatically update internal links" when moving files
- Set "New link format" to "Shortest path when possible"

## Community Plugins (recommended)
- Dataview (for index.md and MOC rendering)
- Templater (for `<% tp.xxx %>` template syntax)
